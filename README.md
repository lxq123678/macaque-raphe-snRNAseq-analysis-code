# Macaque raphe snRNA-seq analysis

Analysis code for:

**A single-nucleus transcriptomic atlas of the dorsal and median raphe regions in adult macaques**
<img width="807" height="767" alt="image" src="https://github.com/user-attachments/assets/f340be03-520d-482e-a072-6e9b10408ab8" />

This repository contains selected analysis code associated with the adult cynomolgus macaque raphe single-nucleus RNA sequencing (snRNA-seq) dataset. The repository includes code for:

1. Preparing and integrating the mouse serotonergic reference datasets;
2. Estimating and correcting ambient RNA contamination in the macaque libraries using SoupX; and
3. Performing ortholog-based macaque–mouse integration and related exploratory comparative analyses.

The repository does not currently contain the complete raw-read processing, quality-control, doublet-detection, major-class annotation, or cell-type annotation pipeline. These procedures are described in the manuscript, and the corresponding processed matrices, Seurat objects, and metadata are provided through the accompanying data deposition.

The final curated dataset comprises 140,674 nuclei from two adult male cynomolgus macaques, Mq246 and Mq277, across 15 technical libraries. It includes seven major cell classes and 57 putative transcriptional cell types, including 14 serotonergic cell types represented by 3,696 nuclei.

The 15 libraries were generated from separate aliquots of animal-specific pooled nuclei suspensions and therefore represent technical libraries rather than independent biological replicates or anatomically distinct samples.

## 2. Data availability

### Macaque data

- GigaDB dataset: [GIGADB_DOI_OR_REVIEWER_LINK]
- CNCB Genome Sequence Archive BioProject: PRJCA077073
- Raw sequencing reads: available through the GSA deposition
- Raw and filtered expression matrices, SoupX-corrected matrices, processed Seurat objects, metadata, and marker tables: available through GigaDB

The SoupX workflow uses the per-library unfiltered droplet matrices and corresponding filtered matrices generated by DNBC4tools.

The cross-species workflow starts from an annotated macaque Seurat object and extracts nuclei assigned to serotonergic cell types. It does not repeat the upstream macaque quality-control or cell-type annotation procedures.

### Mouse reference data

#### Dorsal raphe Pet1 SMART-seq dataset

- GEO accession: GSE144980
- Associated publication: Okaty et al., eLife, 2020
- Number of cells used in this study: 2,350
- Local input file expected by the script: `data/Pet1_sero.rds`

#### Allen Brain Cell Atlas 10x Genomics dataset

- Associated publication: Yao et al., Nature, 2023
- Download location: [Allen Brain Cell Atlas](https://brain-map.org/bkp/explore/abc-atlas)
- Number of serotonergic cells used in this study: 913
- Local input file expected by the script: `data/Allen_sero.rds`

The two mouse datasets differ in sequencing platform, anatomical coverage, cell-selection procedures, and sequencing depth. Dataset of origin was therefore used as a batch variable during within-mouse Harmony integration and subsequent cross-species integration.

Batch correction was used to reduce dataset-associated variation, but it cannot make the datasets technically or anatomically equivalent.

### Ortholog annotation

Macaque–mouse orthologous gene pairs were obtained from Ensembl BioMart.

- Ortholog table supplied in this repository: `mart_export.txt`

After filtering and restricting the analysis to genes detected in both datasets, 13,541 shared orthologous genes were retained for the cross-species analysis.

## 3. Computational environment

The principal analyses were performed using:

- R v4.3.3
- Seurat v5.0.2
- Harmony v1.2.3
- SoupX v1.6.2

Additional packages used by the scripts and notebooks include clustree, clusterProfiler, ggplot2, tidyverse, patchwork, Matrix, ComplexHeatmap, and circlize. Package versions are recorded in `renv.lock`.

To restore the R package environment:

```r
install.packages("renv")
renv::restore()
```

The notebooks require an R kernel and can be run using Jupyter with an R kernel or an equivalent R-compatible notebook environment.

All scripts and notebooks use paths relative to the repository root. The working directory should therefore be set to the repository root before execution.

## 5. Execution order

### Step 1: Prepare the mouse serotonergic reference

**Script:**

```text
00_prepare_mouse_5HT.R
```

**Input:**

- `data/Pet1_sero.rds`
- `data/Allen_sero.rds`

**Processing:**

The script extracts RNA counts and metadata from the two mouse objects, merges the datasets, performs SCTransform and PCA, applies Harmony integration using dataset of origin as the batch variable, evaluates a range of clustering resolutions, performs final clustering at resolution 0.5, and identifies mouse cluster markers.

**Principal output:**

```text
data/mouse_sero.combined_res0.5.rds
```

The script also produces diagnostic clustering, UMAP, clustree, and marker-expression plots.

This step provides the mouse reference used by the cross-species notebook. It does not directly generate a standalone main figure in the manuscript.

### Step 2: Perform ambient-RNA correction

**Notebook:**

```text
01_soupx_correction.ipynb
```

**Input:**

- Per-library unfiltered droplet matrices
- Corresponding filtered cell-containing matrices

**Processing:**

SoupX is applied independently to each macaque library. Library-specific contamination fractions are estimated using `autoEstCont`, and corrected expression counts are generated using the notebook workflow.

**Output:**

- SoupX-corrected expression matrices for the macaque libraries
- Library-specific contamination estimates
- SoupX-related diagnostic outputs generated by the notebook

This step is associated with the Methods section “Read processing and ambient RNA correction” and the ambient-RNA procedures described in “Data validation and quality control”.

Steps 1 and 2 are independent of each other and can be run in either order.

### Step 3: Perform cross-species integration and comparative analyses

**Notebook:**

```text
02_integration_cross_species.ipynb
```

**Input:**

- Annotated macaque Seurat object
- `data/mouse_sero.combined_res0.5.rds`
- Macaque–mouse ortholog table

**Processing:**

The notebook extracts annotated macaque serotonergic nuclei, constructs ortholog-matched macaque and mouse objects, performs batch-aware downsampling where specified, applies SCTransform and PCA, and integrates the datasets using Seurat CCAIntegration.

The notebook also contains code for cross-species visualisation, transcriptional correspondence analyses, marker-list comparison, GO enrichment, and NXPH2-related descriptive analyses.

Alternative exploratory parameter settings are retained in separate notebook sections. Users should identify the final manuscript workflow using the parameters listed below rather than assuming that every alternative section contributes to the reported results.

**Output:**

Outputs generated by the relevant notebook sections include:

- Ortholog-matched macaque and mouse objects
- Batch and cell-type composition summaries
- Cross-species UMAP visualisations
- Cross-species correspondence or overlap tables and plots
- Marker-list overlap outputs
- GO enrichment results
- NXPH2 detection and expression-related outputs

Some `saveRDS()` commands in exploratory sections may be commented out. Users should inspect the relevant notebook section when selecting outputs for further analysis.

## 7. Principal analysis parameters

### Mouse reference preparation

**File:** `00_prepare_mouse_5HT.R`

- Normalisation: SCTransform with glmGamPoi
- Variable features: 5,000
- Computed PCs: 50
- Harmony batch variable: dataset of origin
- Harmony dimensions used downstream: 1–10
- Candidate clustering resolutions: 0.1–1.0 in increments of 0.1
- Final clustering resolution: 0.5
- Marker test: Wilcoxon rank-sum test
- `only.pos`: FALSE
- `logfc.threshold`: 0.25
- `min.pct`: 0.25
- Retained marker genes: adjusted P < 0.01 and avg_log2FC > 1

No explicit random seed is currently set at the beginning of this script. This should be considered when reproducing stochastic clustering and UMAP outputs.

### Ambient-RNA correction

**File:** `01_soupx_correction.ipynb`

- Software: SoupX v1.6.2
- Analysis unit: individual macaque library
- Total-droplet input: unfiltered DNBC4tools matrix
- Cell-containing input: corresponding filtered DNBC4tools matrix
- Contamination estimation: `autoEstCont`
- Estimated contamination fractions in the reported dataset: 8%–13%

### Cross-species integration

**File:** `02_integration_cross_species.ipynb`

- Shared orthologous genes: 13,541
- Downsampling: independently within each batch to the size of the smallest batch
- Cell-type proportions: approximately preserved during downsampling
- Downsampling random seed: 42
- Normalisation: SCTransform with glmGamPoi
- Variable features for the final manuscript analysis: 8000
- Computed PCs: 100
- Integration method: Seurat CCAIntegration
- CCA dimensions: 1–80
- Neighbour-graph and UMAP dimensions: 1–30
- Integrated clustering resolution: 0.1
- Number of mouse neighbours used for label mapping: k = 10

The notebook also contains exploratory analyses using alternative variable-feature numbers and dimensionality settings. These alternatives should not be confused with the final manuscript workflow.

### Marker-list overlap

- Assay: RNA
- Normalisation: NormalizeData
- Test: Wilcoxon rank-sum test
- `only.pos`: TRUE
- `min.pct`: 0.1
- `logfc.threshold`: 1
- Retained markers: adjusted P < 0.01 and avg_log2FC > 1
- Marker lists were pooled within each species, and duplicate gene names were removed before comparison

The resulting overlap describes genes shared between the pooled marker lists. It does not establish cell-type-specific marker conservation or species-specific expression.

### GO enrichment

- Software: clusterProfiler
- Ontology: Biological Process
- Multiple-testing correction: Benjamini–Hochberg
- `pvalueCutoff`: 0.05
- `qvalueCutoff`: 0.2
- Identifier mapping: macaque gene symbols to human Entrez IDs using org.Hs.eg.db
- Background: genes tested by FindAllMarkers that could be mapped successfully to Entrez IDs

The GO analysis describes functional annotations overrepresented in the input gene list and should not be interpreted as demonstrating macaque-specific biological processes.

### NXPH2 detection

NXPH2 detection rates were calculated using the full, non-downsampled macaque and mouse datasets. Detection was defined as nonzero expression in a nucleus or cell.

Differences in detection rates are descriptive and may be influenced by sequencing platform, sequencing depth, nuclear versus whole-cell RNA measurements, anatomical sampling, and gene annotation.

## 8. Interpretation and reproducibility notes

- The current repository provides selected processing and comparative-analysis code rather than a complete end-to-end pipeline from FASTQ files to the final annotated atlas.
- The 15 macaque libraries are technical libraries derived from two animals, not 15 independent biological replicates.
- Cross-species mappings represent exploratory transcriptional correspondences under the specified ortholog-matching and integration workflow. They should not be interpreted as definitive anatomical or functional homology.
- The macaque and mouse datasets differ in sequencing platform, nuclear versus whole-cell RNA measurements, sequencing depth, anatomical coverage, and cell-selection procedures.
- Dataset-only marker membership, GO enrichment, and gene-detection differences do not by themselves establish species-specific expression, conserved cell types, or biological function.
- Cell-type mappings and gene-detection comparisons should therefore be regarded as exploratory and hypothesis-generating.
